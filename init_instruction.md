Tech Stack Requirements: Use React, Tailwind CSS, and Lucide React for icons.

Please create a functional multi-page layout with a navigation bar/sidebar and placeholder data so the UI looks active. Implement the following 4 main views:

1. Authentication View:
- A clean Login and Registration page. "Register as Student".

2. Student Dashboard:
- A "Quick Stats" or overview section.
- A "Book a Session" card/form containing:
  - Dropdown to select an available Ustadz.
  - Date and Time picker.
